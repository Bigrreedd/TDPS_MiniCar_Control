# 🏎️ TDPS_MiniCar_Control - HN KING 微缩车模项目

## 🌟 项目概览
本项目是由 **白紫核大佬** 领衔、**Ray HSiang** (雷皓翔) 及其团队成员开发的基于 **STM32F103** 的高性能微缩车模控制系统。本工程集成了现代嵌入式开发的先进工作流，旨在实现极致的循迹精度与动态响应。

* **领衔开发**：白紫核
* **硬件架构**：STM32F103C8T6
* **传感器逻辑**：LSM6DSR 陀螺仪姿态融合、双编码器速度反馈
* **算法核心**：重心插值寻线算法、双环 PID 控制

## 🛠️ 开发环境：VS Code & Keil 5 协同工作流

为确保开发效率，本项目采用“**编辑与编译分离**”的模式：

### 1. 软件分工
| 软件 | 角色 | 关键职责 |
| :--- | :--- | :--- |
| **VS Code** | **代码编辑器** | 逻辑编写、Git 提交、Live Share 远程协作 |
| **Keil uVision5** | **编译器/调试器** | 硬件配置、编译 (Build)、程序烧录 (Flash) |

### 2. 核心同步设置
> **重要提示**：为实现无缝同步，请务必在 Keil 5 中开启以下设置：
> `Edit` -> `Configuration` -> `Editor` -> 勾选 **`Reload files silently`**。
> 开启后，在 VS Code 保存的任何代码将自动同步至 Keil，无需重新打开文件。

## 📈 算法实现细节 (Technical Implementation)

本项目核心控制器采用增量式 PID 算法，其数学描述如下：

$$u(k) = u(k-1) + K_p [e(k) - e(k-1)] + K_i e(k) + K_d [e(k) - 2e(k-1) + e(k-2)]$$

其中：
* $e(k)$ 为当前误差（循迹偏差或速度偏差）。
* 通过陀螺仪 $Z$ 轴角速度对转向环进行前馈补偿，提高高速过弯时的稳定性。
