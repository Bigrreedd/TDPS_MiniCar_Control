# 风扇电机驱动给队友看的简短说明

用途：解释当前风扇电机电路是否正确、二极管该怎么选、以及“串联电阻”到底是什么。

---

## 1. 这个电路原理有没有错

结论：**原理图拓扑基本是对的**。

它是一个常见的低边 NMOS 开关电路：

```text
11.1V -> 风扇电机 -> MOS 管 -> GND
```

PWM 信号不是直接驱动电机，而是：

```text
STM32 的 FAN_PWM -> UCC27517 栅极驱动器 -> MOS Gate
```

MOS 管导通时，电机通电；MOS 管关断时，电机断电。

因为电机是感性负载，关断瞬间电流不能突然消失，所以需要一个续流二极管。

续流二极管应该这样接：

```text
二极管阴极 -> 11.1V / 电机正端
二极管阳极 -> MOS Drain / 电机负端
```

这样 MOS 关断时，电机电感电流可以通过二极管回到电机正端，避免 MOS Drain 被打出很高尖峰电压。

所以问题不是“这个续流思路错了”，而是：

> 当前电机太猛，二极管、MOS 和 PCB 铜皮可能扛不住。

---

## 2. 二极管可能扛不住，应该选什么类型

当前图里的二极管是 `SS54FSH`，这类通常是 **5A 级肖特基二极管**。

但我们的 30TPA 风扇电机参数很激进：

| 项目 | 电流 |
|---|---:|
| 空载电流 | 1.8A |
| 最大效率点电流 | 11.38A |
| 最大输出点电流 | 35.10A |
| 堵转电流 | 72A |

所以 `SS54FSH` 很可能偏小。

### 2.1 推荐大类

优先考虑这些方向：

1. **大电流肖特基二极管**
   - 优点：导通压降低、速度快、适合电机 PWM 续流。
   - 建议等级：不要按 5A 选，至少看 **20A~40A 级**，并确认浪涌电流和散热。

2. **大电流快恢复二极管 / 超快恢复二极管**
   - 优点：耐压和电流可做得更高。
   - 缺点：正向压降可能比肖特基高，发热更大。

3. **TVS + 更完整的吸收/钳位方案**
   - 适合抑制电源尖峰和振铃。
   - 不能简单替代续流二极管，要结合电路一起设计。

4. **直接使用成熟大电流电调/半桥驱动模块**
   - 如果风扇长期要跑几十安培，这是更稳妥的工程方案。

### 2.2 可参考的器件方向

下面不是唯一答案，只是选型方向：

| 类别 | 可搜索关键词 | 说明 |
|---|---|---|
| 大电流肖特基 | `MBR2045`, `MBR3045`, `MBR4045` | 20A/30A/40A 级，常见但封装较大 |
| 双肖特基 | `STPS30L45`, `STPS40L45` | 低压大电流肖特基，可并联内部管脚使用时要看手册 |
| 车规/功率肖特基 | `40V 30A Schottky diode` | 按 3S 电池系统，耐压建议留余量到 40V 或更高 |
| TVS | `SMBJ18A`, `SMCJ18A`, `SMCJ24A` | 用于电源尖峰吸收，具体电压要按 3S 满电和尖峰裕量选 |

更实际的要求：

- 反向耐压建议至少 `40V`，不要只卡着 12.6V 选；
- 平均电流能力建议至少 `20A` 起步，最好结合实测电流再定；
- 浪涌电流要能承受启动和堵转瞬间；
- 封装不能太小，要能散热；
- PCB 铜皮也要配合加宽，否则换大二极管也没用。

### 2.3 不建议继续用小封装 5A 二极管硬扛

`SS54FSH` 这类 5A 器件可能在短时间、小电流下能工作，但对 30TPA 风扇这种电机不保险。

尤其风扇启动失败或卡住时，电流可能非常大，二极管和 MOS 都可能烧。

## 3. “串联电阻”到底是什么

这里很容易误会。

原理图里的 `10Ω` 不是串在电机主电流回路里的电阻。

它是：

```text
UCC27517 OUT -> 10Ω -> MOS Gate
```

也就是 **MOS 栅极串联电阻**。

它只在 Gate 充放电时有瞬态电流，**不承受电机几十安培主电流**。

### 3.1 10Ω 栅极电阻有什么用

MOS Gate 本质上像一个小电容。

UCC27517 驱动 MOS 时，要给这个 Gate 电容快速充电和放电。10Ω 电阻的作用是：

- 限制 Gate 瞬间充放电电流；
- 减少 Gate 振铃；
- 降低高频尖峰和 EMI；
- 让 MOS 开关边沿不要过于暴力。

所以 10Ω 放在 Gate 上是合理的。

### 3.2 不能把普通电阻串到电机主回路里

不建议这样做：

```text
11.1V -> 风扇电机 -> 大电阻 -> MOS -> GND
```

原因：

- 电机电流可能几十安培；
- 普通电阻会严重发热；
- 电阻功率可能需要几十瓦甚至上百瓦；
- 电机启动能力会变差；
- 发热后阻值变化，控制不可预测；
- 可能烧电阻、烧线、烧板。

如果只是为了测试限流，可以临时用**功率电阻或车灯泡**做假负载，但这不是正式电路方案。

### 3.3 建议加的是 Gate 下拉电阻，不是电机串联电阻

除了 10Ω Gate 串联电阻，还建议加一个 Gate 下拉电阻：

```text
MOS Gate -> GND: 10kΩ ~ 100kΩ
```

这个电阻也不在电机主回路里，不承受大电流。

它的作用是：

- MCU 复位时，MOS 默认关断；
- UCC27517 未上电或异常时，Gate 不会悬空；
- 下载程序、调试、异常复位时，降低误开通风险。

这个电阻一般选 `10kΩ` 或 `100kΩ`，功耗很小，不会导致大电流烧毁。

---

## 4. 最建议怎么改

### 4.1 原理图层面

建议保留当前结构：

```text
UCC27517 + 低边 NMOS + 续流二极管
```

但做这些修改：

1. 把 `SS54FSH` 换成更大电流的续流二极管。
2. 给 MOS Gate 增加 `10kΩ~100kΩ` 下拉电阻到 GND。
3. 在 11.1V 风扇电源入口加更大的低 ESR 电容。
4. 视情况增加 TVS 管吸收尖峰。
5. 核对 MOS 型号 `NCEP40T13GU` 的电流、导通电阻和散热。

### 4.2 PCB 层面

重点不是只换器件，还要看铜皮：

- 风扇电源线要粗；
- MOS Drain/Source 回路要短且宽；
- 续流二极管要靠近电机和 MOS Drain；
- 二极管和 MOS 附近要有足够铜皮散热；
- GND 回流不能绕很长。

### 4.3 测试层面

不要直接接 30TPA 风扇高占空比测试。

建议顺序：

1. 断电万用表确认二极管方向和 MOS 引脚。
2. 不接风扇，用示波器看 Gate PWM。
3. 先接小电流假负载。
4. 再接限流电源。
5. 最后才接风扇，从很低占空比短时点动开始。

---

## 5. 一句话给队友

> 这个电路的原理方向是对的：UCC27517 推 MOS，MOS 开关电机，二极管负责 MOS 关断时续流。真正的问题是 30TPA 风扇电流太大，原来的 SS54FSH 这类 5A 肖特基大概率偏小；应该换成 20A~40A 级的大电流肖特基/快恢复方案，并检查 MOS 和 PCB 铜皮。所谓“串联电阻”不是串在电机里的电阻，而是 MOS Gate 上的 10Ω 小电阻；电机主回路不要乱串普通电阻。建议额外加的是 Gate 到 GND 的 10kΩ~100kΩ 下拉电阻，用来防止 MOS 误开通。
