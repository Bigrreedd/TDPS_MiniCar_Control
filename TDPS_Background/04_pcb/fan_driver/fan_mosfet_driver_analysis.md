## 1. 最终结论

### 1.1 原理图拓扑是否正确

从 `负压主板V2.pdf` 和 `风扇电机电路对应原理图.png` 看，这个风扇电机电路的**基本拓扑是正确的**：

- UCC27517DBVR 作为 MOS 栅极驱动器；
- `FAN_PWM` 输入 UCC27517；
- UCC27517 `OUT` 经过 10Ω 电阻驱动 NMOS Gate；
- 风扇电机接在 `11.1V` 和 NMOS Drain 之间；
- NMOS Source 接 GND；
- 续流二极管并联在风扇电机两端；
- 续流二极管方向应为：
  - **阴极接 `11.1V` / 电机正端**；
  - **阳极接 MOS Drain / 电机负端**。

这个结构是标准的：

```text
+11.1V / VBAT
    |
    +---- 风扇电机 ----+---- NMOS Drain
    |                  |
    |                 |<| 续流二极管
    |                  |
    +------------------+
                       |
                   NMOS Source
                       |
                      GND
```

所以，单纯从“低边 NMOS + 续流二极管”的连接原理看，你队友担心的“这个电路原理是不是完全错了”，我的判断是：

> **原理图拓扑不是错的。它的工作原理成立。**

但是：

> **原理图拓扑正确，不等于这个功率级已经安全。当前设计最大的风险在器件电流能力、PCB 走线/铜皮、电源尖峰吸收和软件测试策略。**

## 2. UCC27517DBVR 的作用

UCC27517DBVR 不是电机驱动芯片，也不是续流器件。它只是一个单通道 MOS 栅极驱动器。

它在本电路中的作用是：

- 接收 MCU 输出的 `FAN_PWM`；
- 把 3.3V 逻辑 PWM 转换成更强的栅极驱动信号；
- 通过 `OUT` 引脚快速给 NMOS Gate 充放电；
- 让 NMOS 更快导通、更快关断，降低开关损耗。

本设计中的连接关系为：

| UCC27517 引脚 | 当前连接 | 判断 |
|---|---|---|
| `VDD` | `11.1V` | UCC27517 供电范围支持 4.5V-18V，3S 满电 12.6V 在范围内 |
| `GND` | 系统地 | 必须与 MCU 地、电池负极、MOS Source 共地 |
| `IN+` | `FAN_PWM` | 非反相输入，输入 PWM |
| `IN-` | GND | 固定为低，使输出跟随 `IN+` |
| `OUT` | 10Ω 后接 NMOS Gate | 合理，用于限制栅极瞬态电流和抑制振铃 |

UCC27517 旁边的 100nF 去耦电容是必要的，但它只负责栅极驱动器本身的瞬态供电，**不能吸收风扇电机的续流能量**。

## 3. 电路工作过程

### 3.1 PWM 高电平：MOS 导通

当 `FAN_PWM` 为高时：

```text
FAN_PWM = 1
UCC27517 OUT = 高电平
NMOS Gate 被拉高
NMOS 导通
```

主电流路径：

```text
11.1V -> 风扇电机 -> NMOS Drain -> NMOS Source -> GND
```

此时：

- MOS Drain 接近 GND；
- 续流二极管阴极在 `11.1V`；
- 续流二极管阳极接近 GND；
- 二极管反向偏置；
- 二极管不导通。

所以你之前说的“正常运行时二极管不发挥作用”是正确的。

### 3.2 PWM 低电平：MOS 关断

当 `FAN_PWM` 为低时：

```text
FAN_PWM = 0
UCC27517 OUT = 低电平
NMOS Gate 被拉低
NMOS 关断
```

风扇电机绕组、电线和电源回路中存在等效电感，电感电流不能突变。因此 MOS 关断瞬间，电机绕组会试图维持原来的电流方向。

为了维持电流，MOS Drain 节点会被抬高。当 Drain 电压高于 `11.1V` 电源轨约一个二极管压降时，续流二极管导通。

续流路径：

```text
MOS Drain / 电机负端 -> 续流二极管 -> 11.1V 电源轨 -> 风扇电机 -> MOS Drain / 电机负端
```

这个过程的作用是：

- 限制 MOS Drain 的过压；
- 给电机电感电流提供衰减回路；
- 避免电感把 MOS Drain 打到很高电压；
- 保护 MOS 管。

更准确的描述是：

> MOS 关断时，风扇电机绕组的电感电流继续沿原方向流动，使 MOS Drain 电压升高；当 Drain 电压高于电机正电源约一个二极管压降后，续流二极管导通，电流通过“Drain → 二极管 → 电源正端 → 电机 → Drain”形成回路，电感能量逐步消耗在绕组电阻、二极管压降、MOS 寄生和电源回路中。

## 4. 图 1 与图 2 的关系

之前的两种画法本质区别不大。

### 4.1 图 1

图 1 把二极管直接画在电机两端，表达非常清楚：

```text
二极管并联在电机两端
```

这是我更推荐的画法。

### 4.2 图 2

图 2 把电机正端、UCC27517 `VDD` 和二极管阴极统一接到 `VCC`。

如果图 2 中：

- `VCC` 实际就是风扇电机电源，也就是 `11.1V` / `VBAT_3S`；
- 二极管阴极接 `VCC`；
- 二极管阳极接 MOS Drain；

那么图 2 和图 1 在电气上等价。

图 2 容易让人困惑，是因为：

- `VCC` 容易被误解成 3.3V 或 5V；
- 二极管没有视觉上贴着电机；
- 标题“负压风扇”容易让人误以为是负电压驱动。

因此，图 2 不一定错，但不建议用这种表达。建议把 `VCC` 改为：

```text
VBAT_3S
MOTOR_11V
FAN_PWR_11V
```

## 5. 当前 PCB 截图能确认什么

从 `风扇电机电路.png` 看，PCB 局部布局与原理图大体对应：

- 风扇接口附近有明显 `11.1V` 电源网络；
- NMOS 功率管靠近风扇接口；
- 续流二极管靠近电机与 MOS 区域；
- UCC27517、10Ω 栅极电阻、MOS Gate 之间距离较近；
- MOS Source 区域连接 GND；
- 功率路径大致符合低边 NMOS 风扇驱动结构。

因此，从截图判断，PCB 并没有表现出“完全画反、完全接错”的明显错误。

但是，仅凭截图还不能 100% 确认以下内容：

- 二极管封装方向是否和原理图符号一致；
- PCB 封装的 1 脚/2 脚是否与实际 SS54FSH 封装一致；
- 风扇接口 1 脚/2 脚是否与实际焊接线序一致；
- MOS 的 Drain/Source/Gate 封装引脚是否与 NCEP40T13GU 数据手册一致；
- 高电流铜皮宽度是否足够；
- 底层蓝色走线是否参与了大电流回路；
- GND 回流路径是否足够宽；
- 二极管到电机/MOS 的续流回路是否足够短。

所以 PCB 的结论应该写成：

> **从截图看，PCB 布局方向与原理图意图基本一致；但必须用 EDA 网络高亮、封装引脚检查和万用表通断测试确认，不能只靠截图判定最终正确。**

## 6. 当前设计真正的高风险点

### 6.1 风扇电机电流非常大

项目记录的风扇电机为 `CHF-130WH-30TPA`。

| 参数 | 数值 |
|---|---:|
| 标称电压 | 11V |
| 空载电流 | 1.8A |
| 最大效率点电流 | 11.38A |
| 最大输出点电流 | 35.10A |
| 堵转电流 | 72.00A |

这不是普通小风扇，而是非常激进的小型高速电机。

这意味着：

- MOS 管要按几十安培级别考虑；
- 二极管要按高脉冲电流考虑；
- PCB 铜皮要按大电流考虑；
- 电池线和接口要按大电流考虑；
- 软件测试不能直接给高占空比；
- 风扇卡住、叶轮擦壳、启动失败都会造成巨大电流。

占空比上限的详细计算见：

```text
TDPS_Background/hardware/motor_pwm_duty_limit_analysis.md
```

按满电 `12.6V` 和风扇电机动态电阻 `0.15Ω` 估算，30TPA 风扇满电堵转电流约 `84A`。在当前 SS54FSH、MOS、PCB 铜皮和线材未完成实测验证前，固件风扇上限应保持 `0 / 1000`；若后续仅做限流台式电源点动，建议不超过 `50 / 1000`。

### 6.2 SS54FSH 可能严重偏小

图中续流二极管标为 `SS54FSH`。

SS54/SS54F 类器件通常是 5A 级肖特基二极管。即便它适合某些小电机续流，也不应默认认为它能承受 30TPA 风扇的 PWM 续流应力。

尤其在这些情况下风险很高：

- 风扇低速启动；
- 风扇堵转；
- 占空比较低但电机电流很大；
- PWM 频率较高，二极管频繁导通；
- PCB 铜皮散热不足；
- 电源线较长导致尖峰更大。

因此，当前设计即使拓扑正确，二极管也可能是薄弱点。

建议：

- 查询 SS54FSH 的实际数据手册；
- 核对平均正向电流；
- 核对浪涌电流；
- 核对封装热阻；
- 核对在实际 PWM 占空比和电机电流下的功耗；
- 必要时换成更大电流的肖特基二极管、TVS 吸收或更完整的电机驱动方案。

### 6.3 MOS 管必须按实际型号核对

图中 MOS 管型号为 `NCEP40T13GU`。

必须核对数据手册中的：

- `VDS` 最大耐压；
- `VGS` 最大耐压；
- 连续漏极电流；
- 脉冲漏极电流；
- `RDS(on)` 在 `VGS=10V` 或 `VGS=12V` 时的值；
- 封装热阻；
- 是否需要大面积铜皮辅助散热。

如果 UCC27517 由 `11.1V/12.6V` 供电，那么 MOS Gate 高电平也接近 `11.1V/12.6V`。这通常有利于降低 `RDS(on)`，但必须确认 MOS 的 `VGS(max)` 足够，一般不能超过 ±20V。

### 6.4 缺少 Gate 下拉会增加误开通风险

原理图里可以看到 10Ω 串联栅极电阻，但没有明显看到 Gate 到 Source/GND 的下拉电阻。

建议增加：

```text
Gate -> GND: 10kΩ ~ 100kΩ
```

作用：

- MCU 复位时让 MOS 默认关断；
- UCC27517 未稳定上电时防止 Gate 漂浮；
- 下载程序、调试、异常复位时降低误开通风险。

UCC27517 有欠压保护和输出能力，但硬件 Gate 下拉仍然是功率 MOS 设计里的常用保险。

### 6.5 电源吸收能力不足

当前 UCC27517 旁边的 100nF 电容只适合本地去耦。

风扇电机需要额外考虑：

- 风扇电源入口的大电解/固态电容；
- 低 ESR 电容；
- TVS 管；
- 电池线长度；
- XT30 接插件和线材电阻；
- 关断时电源轨是否会被回灌抬高。

如果没有足够吸收，MOS 关断时虽然二极管能钳位 Drain，但电源轨仍可能出现尖峰或振铃。

## 7. 必须做的验证清单

在继续上电测试前，建议按下面清单验证。

### 7.1 断电万用表通断测试

断开电池，断开风扇电机。

用万用表蜂鸣档确认：

| 测试点 | 期望结果 |
|---|---|
| 风扇接口正极 | 连到 `11.1V` 电源 |
| 风扇接口负极 | 连到 MOS Drain |
| MOS Source | 连到 GND |
| 续流二极管阴极 | 连到 `11.1V` |
| 续流二极管阳极 | 连到 MOS Drain |
| UCC27517 VDD | 连到 `11.1V` |
| UCC27517 GND | 连到 GND |
| UCC27517 OUT | 经 10Ω 到 MOS Gate |

### 7.2 二极管方向测试

用万用表二极管档：

正表笔接 MOS Drain / 电机负端，负表笔接 `11.1V` / 电机正端。

期望：

```text
读到一个肖特基正向压降，通常约 0.2V ~ 0.5V
```

反过来测应该不导通。

如果测量结果相反，说明二极管方向或封装可能错。

### 7.3 MOS 引脚确认

按 NCEP40T13GU 数据手册确认 PCB 封装：

| MOS 引脚 | 应连接 |
|---|---|
| Gate | UCC27517 OUT 经过 10Ω |
| Drain | 风扇电机负端、续流二极管阳极 |
| Source | GND |

这是板级验证中最关键的部分之一，因为 MOS 封装和符号一旦引脚映射错，原理图看起来正确也会烧板。

### 7.4 EDA 网络高亮

在嘉立创 EDA 中分别高亮：

- `11.1V`
- `GND`
- `FAN_PWM`
- MOS Gate 网络
- MOS Drain / 风扇负端网络

确认：

- `11.1V` 没有短到 GND；
- 风扇正端在 `11.1V`；
- 风扇负端只到 MOS Drain；
- MOS Source 是 GND；
- Gate 只由 UCC27517 OUT 驱动；
- 续流二极管跨接在 `11.1V` 和 MOS Drain 之间。

### 7.5 不接风扇的空载 PWM 测试

不接风扇电机，只接逻辑供电或限流电源。

用示波器测：

| 测试点 | 期望 |
|---|---|
| `FAN_PWM` | MCU 输出 PWM |
| UCC27517 `OUT` | 跟随 `FAN_PWM`，幅度接近 UCC27517 VDD |
| MOS Gate | 经过 10Ω 后同样有 PWM |
| MOS Drain | 不接负载时不应异常短路 |

### 7.6 接假负载测试

不要一开始接 30TPA 风扇。

建议先用：

- 功率电阻；
- 小灯泡；
- 小电流电机；
- 限流台式电源；

确认 MOS 开关行为正常。

### 7.7 最后才接风扇

接 30TPA 风扇时必须：

- 使用限流电源；
- 初始占空比非常低，当前建议限流点动不超过 `50 / 1000`；
- 短时点动；
- 观察电流；
- 观察 MOS 和二极管温升；
- 确认叶轮不卡；
- 确认没有异味、冒烟、啸叫、电流异常。

## 8. 软件占空比建议

详细计算以 `TDPS_Background/hardware/motor_pwm_duty_limit_analysis.md` 为准。

30TPA 风扇额定电压约 11V，3S 电池满电为 12.6V。按平均电压不超过额定值并额外留 20% 余量估算：

```text
duty_voltage_margin = 0.8 × 11.0 / 12.6 ≈ 69.8%
```

如果旧 `M3PWM` 量纲为 `0-1000`，只按电压得到的降额理论值约为：

```text
698 / 1000
```

但是这只是电压角度的理论上限，不是当前板子的安全调试占空比。按满电 `12.6V` 和动态电阻 `0.15Ω` 估算，风扇低速或堵转时电流可达约 `84A`，并且 SS54FSH 级续流二极管、MOS、PCB 铜皮和线材尚未完成实测验证。

因此当前建议为：

| 场景 | 建议 |
|---|---|
| 当前固件 | 保持 `FanMotor_SafetyLock`，风扇上限 `0 / 1000` |
| 不接风扇，只测波形 | 可以测 `FAN_PWM`、UCC27517 `OUT`、MOS Gate，但不接电机负载 |
| 限流台式电源或假负载点动 | 不超过 `50 / 1000` |
| 只按电压计算且留 20% 余量 | `698 / 1000`，不可直接采用 |

不建议再次直接使用：

```text
1000 / 1000
```

也不建议在没有电流测量的情况下持续使用高占空比。

## 9. 给队友看的简短判断

可以这样和队友解释：

> 这个风扇电机电路的原理图拓扑是标准的低边 NMOS PWM 驱动。UCC27517 负责把 MCU 的 PWM 变成强栅极驱动，NMOS 负责开关风扇电机，SS54FSH 续流二极管在 MOS 关断时给电机电感电流提供回路。因此从拓扑上看不是错电路。  
> 但这个电路目前不能直接认定为安全，因为 30TPA 风扇电机电流非常大，最大输出点约 35A、堵转约 72A。SS54FSH、MOS 管、PCB 铜皮、电源电容和软件占空比都必须重新按几十安培级别验证。也就是说，问题不在“有没有续流二极管”这个原理，而在“这个续流二极管和整套功率路径够不够扛”。  
> 结论：拓扑基本正确，但功率级未验证，不能直接高占空比上电测试。
