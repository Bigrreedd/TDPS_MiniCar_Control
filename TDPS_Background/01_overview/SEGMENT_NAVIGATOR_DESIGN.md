# SegmentNavigator 比赛全程导航架构（v1 设计稿）

> 2026-06-05 主控合成。输入：route-spec 段表/协议提取终稿 + practice-scout 智能车实践调研（memory/tdps-smartcar-statemachine-survey.md）+ 精确地图转录 + 审查组全部裁决。
> 状态：**设计稿，待两件事后实施**——① 用户拍板路线顺序（C-1/C-2）② 红队评审。

## 0. 合规边界（设计第一约束，来自任务书"不可预编程路线"）

- 一切段转移由**实测路标触发**（灰度/陀螺/编码器/ESP 信号），不存在"第 N 个岔路走左"式查表
- 全程沿线行驶；**唯一合法弃线区 = 雷达障碍箱**（规则明示 CP1.4 切 radar signature）
- yaw 闭环只用于：弃线区直推姿态保持、丢线瞬间姿态限幅——**捕线即交还灰度循迹**
- 完全离线 → 从上一检查点重启（段状态机需可从任意 checkpoint 段冷启动）

## 1. 分层架构

```
L3 执行模式层   FOLLOW_LINE / FOLLOW_TIGHT(深弯) / JUNCTION_STRAIGHT(冻结)
                / RADAR_CREEP_STOP(减速→停→握手) / DEAD_RECKON_PASS(弃线直推)
                / FINISH_STOP(ARCH2+2s)
L2 SegmentNavigator  段表驱动：入口谓词→段动作+参数档→出口谓词→超时兜底
                ├── 段独占锁（唯一裁决者：深弯/路口冻结/Path弯检测 谁有权动转向）
                └── 退出锁存窗（出段后 X cm/X s 内禁止再识别同类路标）
L1 路标事件总线  JC_INC / U_LATCH(yw≥150°) / YAW_DELTA / DIST_WINDOW
                / ARCH_PASSED(n) / RADAR_DECISION / LINE_REACQ / ALL_BLACK
                （每事件带 时间戳+里程戳+置信度；距离窗对事件做合理性门控）
L0 传感原语(已有) pos/junction/jc · yw/u · el,er→里程(标定中) · ESP锚点(链路待通)
```

> **v1.1 增订（06-05 晚）**：队友坐标级描述文档落地后，路线顺序定稿为 **S2→长直→U弯→下行→蛇形①→拱门2.1→方块阵→四圆→雷达→S胶囊②→拱门2.2→Finish**（详见 00_course/赛道地图_右侧精确版_转录_2026-06-05.md v2，含累计里程账 ≈21.8m）。本节 route-spec 旧段表的 1↔5 段顺序作废，以转录 v2 段表为准。**S-mode 触发链同步重设计**：旧 `jc≥2&&u=1` 作废（正式图直线无 Y、拱门 2.1 在蛇形①之后）；触发 v2 = `u==1` + 内侧下行里程窗(345cm)或 yw 稳定 180°±15°，蛇形①出口锚 = ARCH(1)。C-1/C-2/C-3 三冲突已解；D-7 静默窗经里程账核算安全（2.1 在 ~10.9m ≈30s+）。ESP 锚点链路已在 pcb2 实装（USART1，ec990f5）。

## 2. 段表（路线内容引 route-spec 终稿 A，13 段，S2→Finish 精确地图序）

每段一行五元组：`{入口谓词, 执行模式, 参数档, 出口谓词, 超时兜底}`。里程列**全部待标定**（编码器 CPR + C-1 拍板后回填）。要点：

- 双 Y 标识段（3/5）：JUNCTION_STRAIGHT 政策 + 退出锁存窗（双 Y 间隔仅 20~30cm，是二次误触发头号风险——scout 模式④）
- 大 U 弯（4）：FOLLOW_TIGHT，段锁禁止路口冻结抢转向（审查 C4 的运行时第二道保险）
- 方块阵（7）：真 T 字冻结直穿；**Y 岔与十字在宽黑内分流**（scout 模式⑤：突然全黑/span 满→直穿；渐开单侧 span 增→保持循迹转向）
- 四圆区（8）：下连线 T 字冻结直穿；顶部连线段须主动转向（直穿=丢线）——依赖连续性选段+方向一致性约束（route-spec 已标 last_precise 污染风险）
- 雷达段（9/10）：CREEP_STOP→AT_POSITION→等 DECISION（超时 500ms 重发 ×1；UNKNOWN→停更久再请求，**不预设方向**——障碍随机，预设=50% 撞）→DEAD_RECKON_PASS（yaw 保持直行+里程推进+空闲侧偏移，**双退出**=里程到位 OR 连续 N 拍多数表决重捕黑线）
- Finish（13）：权威触发=ARCH_PASSED(2)+2s（沟通记录），里程门做 backup

## 3. 参数档表（S-mode 的全面泛化）

每段一行：`{target_cps, floor/cap 对(保持差=20 不变量), 深弯使能/阈值, 路口政策, 修正钳位}`。现 S-mode = 表中一行的特例，实施后 S-mode 锁存机制并入段表（顺带解决审查 P9 "S-mode 永不释放"——段表天然有出口）。

## 4. 切换瞬态纪律（scout Q3，硬规则）

段切换时必须：清速度环积分 → 复位位置环 last_error/d_filtered（R5 软启动的泛化）→ 目标速度走斜坡非阶跃（与 adaptive-decel-flicker 记忆同向）。

## 5. 分阶段实施（每阶段单独可测，不破坏现有调参成果）

| 阶段 | 内容 | 前置 |
|---|---|---|
