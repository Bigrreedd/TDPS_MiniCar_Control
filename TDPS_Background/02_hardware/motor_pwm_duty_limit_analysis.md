# 电机 PWM 占空比上限计算与降额建议

记录时间：2026-05-21

本文基于当前已确认的电机、电池和风扇驱动资料，重新计算左右轮电机与风扇电机的 PWM 占空比上限。本文只给出硬件安全估算和未来恢复测试时的限幅建议，**不代表当前固件可以解除安全锁**。

## 1. 已知条件

### 1.1 电池

| 参数 | 数值 |
|---|---:|
| 型号 | Tattu 3S 850mAh 75C LiPo |
| 标称电压 | 11.1V |
| 满电电压 | 12.6V |
| 容量 | 0.85Ah |
| 标称倍率 | 75C |
| 理论倍率电流 | 0.85Ah × 75C = 63.75A |

注意：`63.75A` 只是电池标签倍率换算，不代表 PCB、MOS、二极管、线材、接插件和电机都能安全承受这个电流。

### 1.2 左右轮电机：CHF-130WH-50TPA

| 参数 | 数值 |
|---|---:|
| 标称电压 | 11.1V |
| 空载电流 | 0.90A |
| 最大效率点电流 | 4.95A |
| 最大输出点电流 | 14.06A |
| 堵转电流 | 27.23A |

由额定电压和堵转电流估算电枢等效电阻：

```text
R_wheel ≈ 11.1V / 27.23A ≈ 0.408Ω
```

满电 12.6V 下，如果低速或堵转时直接给 PWM，单个轮子电机等效堵转电流约为：

```text
I_stall_full_wheel ≈ 12.6V / 0.408Ω ≈ 30.9A
```

两个轮子同时堵转时约为：

```text
I_stall_full_2wheels ≈ 2 × 30.9A ≈ 61.8A
```

这已经非常接近电池 `63.75A` 的理论倍率电流，还没有计入驱动损耗、线损和电池内阻压降。

### 1.3 风扇电机：CHF-130WH-30TPA

| 参数 | 数值 |
|---|---:|
| 标称电压 | 11.0V |
| 空载电流 | 1.8A |
| 最大效率点电流 | 11.38A |
| 最大输出点电流 | 35.10A |
| 堵转电流 | 72.00A |
| 动态电阻 | 0.15Ω |

满电 12.6V 下，风扇电机低速或堵转时电流估算为：

```text
I_stall_full_fan ≈ 12.6V / 0.15Ω = 84A
```

单个风扇电机的满电堵转电流已经超过电池 `75C` 理论电流。它不是普通小风扇，不能用普通低功率 PWM 测试方法处理。

### 1.4 风扇驱动功率级约束

当前风扇驱动拓扑为：

```text
VBAT_3S -> 风扇电机 -> NMOS -> GND
```

并使用 UCC27517 栅极驱动器、NCEP40T13GU NMOS 和 SS54FSH 类肖特基续流二极管。拓扑本身成立，但风扇电机电流很大，安全上限不只由电机额定电压决定，还受到以下因素限制：

- SS54/SS54F 类二极管通常是约 5A 级器件，不应默认承受 30TPA 风扇的 PWM 续流应力；
- MOS 的封装散热、`RDS(on)`、脉冲电流和 PCB 铜皮面积尚需实测确认；
- 风扇堵转、叶轮擦壳、启动失败会让电流接近堵转模型；
- 当前固件已经改成 `FanMotor_SafetyLock`，风扇 PWM 不输出。

## 2. 计算方法

本文把占空比上限分为三类：

| 类型 | 含义 | 是否可作为固件上限 |
|---|---|---|
| 电压理论上限 | 只保证平均电压不超过电机额定电压 | 不可单独作为安全上限 |
| 加 20% 余量后的电压上限 | 平均电压按额定值再降额 20% | 仍不可单独作为安全上限 |
| 电流降额上限 | 按满电、低速/堵转模型限制电流 | 可作为无电流传感器时的固件硬上限参考 |

### 2.1 电压模型

```text
V_motor_avg ≈ D × V_batt_full
D_voltage = V_motor_rated / V_batt_full
D_voltage_margin = 0.8 × D_voltage
```

这里使用 `0.8` 表示预留 20% 电压余量。

### 2.2 低速/堵转电流模型

低速、起步失败或堵转时，反电动势很小，电流主要由电枢电阻决定：

```text
I ≈ D × V_batt_full / R_motor
```

所以要把电流限制到某个目标值 `I_limit`，占空比应满足：

```text
D_current ≤ I_limit / I_stall_full
```

再预留 20% 余量：

```text
D_current_margin = 0.8 × I_limit / I_stall_full
```

## 3. 左右轮电机计算结果

### 3.1 只按电压计算

```text
D_voltage_wheel = 11.1 / 12.6 = 0.881
D_voltage_margin_wheel = 0.8 × 0.881 = 0.705
```

换算成 TIM1 代码量纲 `0-10000`：

```text
理论电压上限：约 8810 / 10000
留 20% 余量后：约 7050 / 10000
```

但是这个上限只考虑平均电压，不考虑起步/堵转电流。对当前车来说，**不能把 7050 当作固件安全上限**。

### 3.2 按最大输出点电流降额

单个轮子满电堵转电流约 `30.9A`。若把单个轮子电机电流限制到最大输出点电流 `14.06A`，并留 20% 余量：

```text
D_wheel_max_output_margin = 0.8 × 14.06 / 30.9 ≈ 0.364
```

换算成 TIM1 代码量纲：

```text
约 3640 / 10000
```

此时低速/堵转估算电流：

```text
单电机：30.9A × 0.364 ≈ 11.25A
双电机：约 22.5A
```

这个电流比两个轮子最大输出点合计电流 `28.12A` 低约 20%，也明显低于电池理论 `63.75A`。因此，在没有电流传感器、没有确认驱动板热能力之前，`3500 / 10000` 更接近“留余量后的轮子电机最高固件硬上限”。

### 3.3 按最大效率点电流降额

若按更保守的最大效率点电流 `4.95A`，并留 20% 余量：

```text
D_wheel_efficiency_margin = 0.8 × 4.95 / 30.9 ≈ 0.128
```

换算成 TIM1 代码量纲：

```text
约 1280 / 10000
```

这更适合作为首次带轮、架空或低速调试范围，而不是最终性能上限。

### 3.4 左右轮结论

| 用途 | 建议占空比 | TIM1 代码量纲 |
|---|---:|---:|
| 首次恢复、架空、短时调试 | 5% ~ 10% | 500 ~ 1000 / 10000 |
| 保守低速调试上限 | 约 13% | 1300 / 10000 |
| 当前无电流传感器的建议固件硬上限 | 20% | 2000 / 10000 |
| 完成电流/温升验证后的短时上限候选 | 不超过 35% | ≤ 3500 / 10000 |
| 只按电压且留 20% 余量的理论上限 | 约 70% | 7050 / 10000 |

最终建议：

- 当前 `MOTOR_DUTY_SAFE_MAX = 2000` 是合理的保守固件硬限幅，不建议提高。
- 在没有电流采样、保险、温升验证前，不应超过 `2000 / 10000`。
- 即使后续恢复性能测试，也建议先把“可申请的短时最高值”限制在 `3500 / 10000` 以内。
- `7050 / 10000` 只是电压额定降额上限，不能作为当前固件上限。

## 4. 风扇电机计算结果

### 4.1 只按电压计算

```text
D_voltage_fan = 11.0 / 12.6 = 0.873
D_voltage_margin_fan = 0.8 × 0.873 = 0.698
```

如果使用旧 `M3PWM` 的 `0-1000` 量纲：

```text
理论电压上限：约 873 / 1000
留 20% 余量后：约 698 / 1000
```

这个值只说明平均电压不超过额定电压，**不能说明风扇驱动电路能承受该占空比**。

### 4.2 按最大输出点电流降额

满电低速/堵转模型下，风扇电机电流约 `84A × D`。若把电流限制到最大输出点电流 `35.10A` 并留 20% 余量：

```text
D_fan_max_output_margin = 0.8 × 35.10 / 84 ≈ 0.334
```

换算成旧 `M3PWM` 代码量纲：

```text
约 334 / 1000
```

这已经是非常激进的电流等级，且没有解决 SS54FSH、MOS、PCB 铜皮和线材的热限制。

### 4.3 按最大效率点电流降额

若按最大效率点电流 `11.38A` 并留 20% 余量：

```text
D_fan_efficiency_margin = 0.8 × 11.38 / 84 ≈ 0.108
```

换算成旧 `M3PWM` 代码量纲：

```text
约 108 / 1000
```

即使这个值看起来只有约 10.8%，堵转/起步失败时估算电流仍约：

```text
84A × 0.108 ≈ 9.1A
```

这已经超过常见 SS54 类 5A 肖特基二极管的直观安全范围。

### 4.4 受 SS54FSH 续流二极管约束的粗略估算

对低边 PWM 感性负载，MOS 关断期间续流二极管会承受电机电流。非常粗略地看，若堵转模型下电机平均电流近似为：

```text
I_motor ≈ D × 84A
```

二极管平均续流压力可按下式做保守提醒：

```text
I_diode_avg_rough ≈ I_motor × (1 - D) ≈ 84A × D × (1 - D)
```

若希望把这个粗略平均值限制在约 `4A`，也就是给 5A 级二极管留约 20% 余量：

```text
84 × D × (1 - D) ≤ 4
```

较小占空比解约为：

```text
D ≈ 0.05
```

换算成旧 `M3PWM` 量纲：

```text
约 50 / 1000
```

这个模型很粗糙，不能作为保证值；它的意义是说明：**在当前 SS54FSH 级别续流二极管和未验证 PCB 铜皮条件下，风扇非零 PWM 本身就高度危险**。

### 4.5 风扇结论

| 用途 | 建议占空比 | 旧 M3PWM 代码量纲 |
|---|---:|---:|
| 当前固件状态 | 0% | 0 / 1000 |
| 不接风扇、只测驱动波形 | 0% 负载电流 | 仅示波器测逻辑，不接电机 |
| 接假负载或限流电源点动 | ≤ 5% | ≤ 50 / 1000 |
| 按最大效率点电流降额的理论值 | 约 10.8% | 108 / 1000 |
| 按最大输出点电流降额的理论值 | 约 33.4% | 334 / 1000 |
| 只按电压且留 20% 余量的理论值 | 约 69.8% | 698 / 1000 |

最终建议：

- 当前风扇固件上限应保持 `0`，也就是继续使用 `FanMotor_SafetyLock`。
- 在 SS54FSH、NCEP40T13GU、PCB 铜皮、线材和接口没有实测确认前，不应接 LiPo 给风扇做非零 PWM。
- 若必须验证风扇功率级，应使用限流台式电源、假负载或短时点动，初始不超过 `50 / 1000`，并观察电流和温升。
- `108 / 1000`、`334 / 1000`、`698 / 1000` 都只是理论分层值，不是当前板子的安全授权值。

## 5. 固件限幅建议

### 5.1 当前阶段

当前阶段仍处于硬件排查安全锁状态：

| 对象 | 当前建议 |
|---|---|
| 左右轮电机 | 不调用 `Motor_Enable()`，保持 `MOTOR_DUTY_SAFE_MAX = 2000` 不提高 |
| 风扇电机 | 保持 `FanMotor_SafetyLock`，不恢复 `M3PWM` 输出 |

### 5.2 后续若恢复轮子测试

建议逐级恢复：

| 阶段 | 上限 | 条件 |
|---|---:|---|
| 架空空载 | 500 ~ 1000 / 10000 | 可立即断电，观察方向和编码器 |
| 地面低速 | 1000 ~ 1500 / 10000 | 电机、驱动、线材无异常发热 |
| 保守闭环 | 2000 / 10000 | 当前 `MOTOR_DUTY_SAFE_MAX`，不建议提高 |
| 短时性能验证 | ≤ 3500 / 10000 | 需要电流测量、保险和温升记录 |

不建议在当前硬件验证阶段把 `MOTOR_DUTY_SAFE_MAX` 提高到 `3500` 以上。

### 5.3 后续若恢复风扇测试

恢复风扇前必须先完成：

- 确认叶轮无卡滞、无擦壳；
- 用万用表确认风扇接口、MOS、二极管方向；
- 确认 NCEP40T13GU 的封装引脚、`RDS(on)` 和散热条件；
- 确认 SS54FSH 的实际平均电流、浪涌电流和热阻；
- 使用限流台式电源或保险，不直接用 LiPo 高占空比冲击；
- 有示波器观察 `FAN_PWM`、UCC27517 `OUT`、MOS Gate 和 Drain。

在这些条件满足前，风扇固件上限应继续为：

```text
FAN_MOTOR_SAFE_DUTY_OFF = 0
```

## 6. 总结

| 电机 | 推荐当前固件上限 | 留余量后的未来短时上限候选 | 不可直接采用的理论电压上限 |
|---|---:|---:|---:|
| 50TPA 左右轮电机 | 2000 / 10000 | ≤ 3500 / 10000 | 7050 / 10000 |
| 30TPA 风扇电机 | 0 / 1000 | 当前板未验证前不建议非零；限流点动 ≤ 50 / 1000 | 698 / 1000 |

最重要的结论：

- 左右轮电机：当前 `2000 / 10000` 是合理保守值，未来即使解锁，也不应一开始超过这个值。
- 风扇电机：受 84A 满电堵转模型和 SS54FSH/PCB 未验证限制，当前软件上限应继续为 `0`。
- 只按额定电压算出的 70% 左右占空比不能用于当前固件，因为它完全没有覆盖起步、堵转、续流二极管、MOS 热和 PCB 铜皮风险。

## 7. 2026-06-05 增补：系统级约束补全 + 三电机上限定版（已落代码）

### 7.1 本文 5-21 版遗漏的系统级约束：XT30 接插件 15A

PCB6 BOM 自标"XT30AW 防水锁扣镀金 **15A** 二芯公插头"。全车电流走这一个接插件，
它比电池 75C(63.75A) 紧 4 倍，是除风扇续流二极管外最紧的系统约束。约束链定版：

```text
SS54FSH 续流二极管(~5A,风扇专属) < XT30(15A,系统总线) ≤ 双层板铜皮(未实测,按不优于XT30) < 电池75C(63.75A) < NCEP40T13GU(电气余量大,热未验证)
```

### 7.2 轮子优先分配（定版）

```text
双轮 @ MOTOR_DUTY_SAFE_MAX=2000(20%) 满电堵转: 2 × 12.6V/0.408Ω × 0.20 = 12.36A
+ 双板逻辑/传感 ≈ 0.5A → 12.86A < 15A，余 2.14A
```

**结论：SAFE_MAX=2000 不仅是 5-21 版的保守建议，而且恰好就是轮子优先下 XT30 允许的上限——禁止上调**（再高则发车/深弯双轮堵转工况顶穿接插件）。上板 ClampMotorDutyFinal=1940 与之一致。

### 7.3 风扇上限定版（三档授权 + 双层钳位，已落代码 LHX/lower-pid b0c8d62）

| 档 | 条件 | 上限(0-1000) | 代码落点 |
|---|---|---:|---|
| 现状锁定 | 叶轮/二极管/铜皮未验证 | 0 | FAN_MOTOR_UNLOCKED=0（FanMotor_SafetyLock.h） |
| 并发档 | 任一轮 duty>1500（发车/深弯/堵转） | **20**（=0.8×2.14A/84A） | FanMotor_RequestDuty 门控 |
| 巡航档 | 双轮 duty 均≤1500 | **50**（二极管 84·D·(1-D)≤4A 钳制） | 同上 + M3PWM_SetDutyCycle 底层硬钳 |
| 升级候选 | 换≥20A二极管+铜皮实测后 | ~110（效率点） | 届时修改 ABS_CAP，需重审 |

双层钳位设计：FanMotor_RequestDuty（策略层，轮子优先）+ M3PWM_SetDutyCycle 无条件硬钳
FAN_DUTY_ABS_CAP=50（机制层）——任何代码路径（含绕过 SafetyLock 的未来误用）都无法超过 5%。

### 7.4 解锁三条件（FAN_MOTOR_UNLOCKED 0→1 前缺一不可）

1. SS54FSH 更换为 ≥20A 续流二极管（或改同步整流）
2. 双层板铜皮在目标电流下温升实测合格
3. 加入电流采样（无实测电流就没有资格谈更高占空比）

### 7.5 与今日其他结论的衔接

- DRV8701E duty=0=慢衰减刹车（17:10 销账）：轮电机刹车相电流走低边 MOS 环流，不过 XT30——刹车不计入总线预算 ✓
- 电池债（审查 C3）：本节全部按满电 12.6V 计算=最坏电流情形；亏电时电流降低，预算只会更安全（与"亏电失速"是同一物理的两面）
- 风扇上车后若与 S-mode 并存：S-mode 降速段双轮 duty 低，恰好落巡航档——但 90° pivot 段（深弯）会触发并发档 20，固件已自动处理
